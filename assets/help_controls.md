# Controls

- Tap a tile to play it (if there's only one valid side it is placed automatically). If tile can be played at both ends, select green marker at desired end to be played.  
Note: When you tap the Settings icon, the current game score is reset.
- AI Level: Tap the Settings icon to change the AI level: Rockie, Casual, Pro or Legend.
- Scoring System: Tap Settings and choose First to Target or Six Love.
