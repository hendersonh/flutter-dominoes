# Scoring Modes

- First to Target Points Match: Points are calculated based on the dots remaining in opponents' hands. First to user defined points: (100, 150 or 200) wins the match.
- Meaning of 2/60 indicator below players name: 2 = tiles in hand, 60 = score 
- Six-Love (Running Champion): Rounds are won as "sets."
- Winner gets +10 points.
- Others get -5 points.
- If all players hits 1 point the game is "Bruk" and everyone resets.
- The "Champion" is tracked across sessions.
